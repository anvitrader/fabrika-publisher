Privacy Policy

This policy explains what data Fabrika Publisher uses. The tool is used only by its owner, Anton Panasenko.

Data we access

  • Basic TikTok profile information of the connected account: open ID, display name and avatar (scope user.info.basic), shown in the dashboard so the owner can see which account he is posting to.
  • Permission to upload and publish videos to that account (scopes video.upload, video.publish).
  • Publishing status responses returned by TikTok for videos the owner publishes.

How data is stored

The TikTok access token is stored only on the owner's own computer in a file readable only by the owner (the computer's disk is encrypted). No data is stored on servers of this website. This website only hosts these pages and a login redirect page, it has no cookies, analytics or advertising.

Sharing

We do not sell, rent or share any data with third parties. Videos are sent only to TikTok, at the owner's explicit request.

Deletion

Disconnect the tool in the TikTok app (Settings and privacy → Security → Manage app permissions). The local token is then deleted by the owner. To request deletion or ask a question, write to anvitrader@gmail.com.
